    Detailed Description¶

    Grid provides a fluent interface for organizing UI elements in a grid. Each SliceRow()/SliceCol() returns a new Grid representing the cell.

    Grid grid({0,0}, {16,8});
grid.SliceRow(2).Draw(element1);
grid.SliceRow(2).SliceCol(2).Draw(element2);
grid.SliceRow(2).SliceCol(2).Clear();
grid.Rest().Clear();
